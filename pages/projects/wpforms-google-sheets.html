The Engineering Challenge

Standard WordPress webhook integrations fail silently under load. When a high-traffic campaign drives dozens of form submissions simultaneously, standard synchronous HTTP requests to the Google Sheets API exhaust PHP worker processes, hit Google's strict 300 writes/minute quota, and trigger connection timeouts. Unhandled exceptions leave visitors with broken checkout or contact pages and result in lost revenue.

Architectural Solution

I engineered a decoupled, event-driven synchronization engine. Rather than executing network requests inline during the WPForms submission lifecycle, submissions are validated, tokenized, and committed to a local high-performance transactional database queue in under 4ms.

A background queue consumer dispatches batched append requests via Google Sheets API v4 using authenticated service account credentials or OAuth 2.0 refresh tokens, featuring exponential backoff and jittered retry mechanics.

Production Queue Worker Pipeline

PHP 8.3 · PSR-12 · Type Safe
src/Queue/SheetsBatchProcessor.php Strict Types 
declare(strict_types=1);

namespace Jewel\WPFormsSheets\Queue;

use Jewel\WPFormsSheets\Auth\TokenVault;
use Google\Service\Sheets;
use Google\Service\Sheets\ValueRange;

final class SheetsBatchProcessor
{
    public function __construct(
        private readonly TokenVault $vault,
        private readonly Sheets $sheetsService,
        private readonly LoggerInterface $logger
    ) {}

    public function processBatch(array $entries, string $spreadsheetId, string $range): BatchResult
    {
        $rows = array_map(fn(FormEntry $entry) => $entry->toRowVector(), $entries);
        $body = new ValueRange(['values' => $rows]);

        try {
            $response = $this->sheetsService->spreadsheets_values->append(
                $spreadsheetId,
                $range,
                $body,
                ['valueInputOption' => 'USER_ENTERED']
            );

            $this->logger->info('Appended batch successfully', ['count' => count($rows)]);
            return BatchResult::success(count($rows));
        } catch (\Google\Service\Exception $e) {
            if ($e->getCode() === 429) {
                return BatchResult::retryRequired(backoffSeconds: 15);
            }
            throw $e;
        }
    }
}
